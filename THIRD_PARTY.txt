IMAGE / GAME ASSETS
===================
The assets directory contains RuneScape puzzle artwork, interface fragments,
rune images, and captured puzzle test images obtained from Clue Trainer's
public static assets, for recognition and compatibility with game pixels.
RuneScape and its game artwork are the property of Jagex Ltd. Other marks
and artwork remain the property of their respective holders.

Clue Trainer's MIT license does not extend to its static image assets.
The MIT license on this helper's code does not relicense those images.
These assets are not represented as original helper artwork.

Upstream paths: static/alt1anchors/modal, static/alt1anchors/sliders,
static/alt1anchors/lockbox_tiles, static/alt1anchors/knot_runes,
static/data/sliders/sliders, static/test_assets/sliders.

No endorsement by Jagex, RuneApps, Clue Trainer or Kavros is implied.

LEGACY TOWER FONT (v0.2.2)
The legacy-digits.txt compatibility data contains only the 1-5 glyph
pixel definitions from alt1 0.1.3, fonts/aa_10px_mono.js, distributed at
https://unpkg.com/alt1@0.1.3/fonts/aa_10px_mono.js .
It is RuneScape font reference data for recognising existing game pixels;
no JavaScript from the font module is included or executed by the helper.
Original font/game artwork remains the property of its respective holder.

Map data/rendering is credited to Skillbert / RuneApps; game world artwork
belongs to Jagex Ltd. These map images are reference game assets and are
not relicensed by this helper's source-code license.
The map transform follows Clue Trainer's MIT-licensed
src/lib/gamemap/GameMap.ts (retrieved 16 November 2026).

Master text masks and regression screenshots contain supplied Kavros

SLIDER ROUTE SEARCH (v0.6.0)
Original helper implementation of additive disjoint pattern databases, IDA*,
weighted A* and route shortcut search. Pattern tables are independently
generated by source/tools/BuildSliderPatterns.cs; per-table SHA-256 files
are checked at load time. Missing/corrupt tables fall back to the base
heuristic. Search-method reference: Korf and Felner, Disjoint Pattern Database
Heuristics (2002), https://web.cs.ucla.edu/~korf/publications.html
No excluded oldlib/skillbertssolver implementation is incorporated.

APPLICATION UPDATES
Setup.exe and the portable package check GitHub Releases with Velopack 1.2.161
(MIT, https://github.com/velopack/velopack). Release feeds are read with
Newtonsoft.Json 13.0.4 (MIT, https://www.newtonsoft.com/json).
Neither library is used for clue solving.
